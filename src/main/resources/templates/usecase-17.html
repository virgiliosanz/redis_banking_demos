UC17

AI Agent Coordination

How it works
  1. Coordinator decomposes one banking query into 4 specialist tasks and appends them to uc17:stream:tasks.
  2. Consumer group workers pick up tasks with XREADGROUP, enrich them with tools + RAG, and write progress back through Redis Streams.
  3. Each agent card updates independently as agent-start, agent-thinking, agent-searching, agent-tools, agent-reasoning, and agent-done SSE events arrive.
  4. Coordinator assembly waits for all results, assembles the final answer, and shows the full coordination trail in the UI.

Code Showcase

# Coordinator fan-out — one task per specialist
XADD uc17:stream:tasks * \
  sessionId "coord-001" agent "risk" role "Risk Analyst" \
  task "Assess portfolio concentration, volatility, and exposure"

XADD uc17:stream:tasks * \
  sessionId "coord-001" agent "compliance" role "Compliance Advisor" \
  task "Review MiFID II, PSD2, and GDPR obligations"

# Results come back on a separate stream
XADD uc17:stream:results * \
  sessionId "coord-001" agent "risk" latencyMs "214" \
  tokensUsed "326" status "done"
# Create the specialist worker group once
XGROUP CREATE uc17:stream:tasks uc17-agents 0 MKSTREAM

# Coordinator can inspect pending deliveries
XPENDING uc17:stream:tasks uc17-agents

# Resetting the demo may recreate the group after key cleanup
DEL uc17:stream:tasks uc17:stream:results uc17:stream:events
# Each agent consumes its assigned work from the group
XREADGROUP GROUP uc17-agents risk-analyst COUNT 1 BLOCK 2000 \
  STREAMS uc17:stream:tasks >

# After tool calls + RAG, acknowledge completion
XACK uc17:stream:tasks uc17-agents 1717000000000-0

# Agents also append an observability event for the UI timeline
XADD uc17:stream:events * agent "risk" stage "tools" \
  detail "vectorSearchKB + portfolio metrics"
# Inspect recent task + result traffic
XINFO GROUPS uc17:stream:tasks
XINFO CONSUMERS uc17:stream:tasks uc17-agents

XRANGE uc17:stream:results - + COUNT 20
XPENDING uc17:stream:tasks uc17-agents
XREVRANGE uc17:stream:events + - COUNT 10
